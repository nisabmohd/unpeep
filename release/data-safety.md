# Data safety (Play Console answers)

- Does the app collect or share any of the required user data types? **No.**
- Is all user data encrypted in transit? Not applicable (no data is sent).
- Can users request data deletion? Not applicable; everything is on the device and is deleted with the app.
- Permissions explained in the listing and PRIVACY.md: location (the Hotspots check only: Android requires it to list
  Wi-Fi names; the position is never read, stored or sent), Bluetooth scan (neverForLocation), camera (lens and infrared finders).
- Play In-App Review (play build only) is Google's; it collects nothing for us.
